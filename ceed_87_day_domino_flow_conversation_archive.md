### Strategy: Relative Sequential Blocks (Wake + X)
The real culprit behind failing to stick to a schedule when sleep is erratic is **clock-time rigidity**. If a schedule says "9:00 AM: Solve Paper" and you wake up at 10:30 AM, your brain registers the day as "already ruined," and the whole plan collapses.

To make the 87-day plan bulletproof, ditch clock times entirely and use a **Sequential Block System (Wake + X)** combined with **Minimum Viable Floors and Open Ceilings**. No matter what time you wake up, the clock starts at **Hour 0:00 (Wake Up)**.

#### 1. Your 4 Non-Negotiables (Floors vs. Ceilings)
| Block Code | Non-Negotiable Pillar | Minimum Floor | Expanded Ceiling | Rules of Engagement |
| :--- | :--- | :--- | :--- | :--- |
| **BLOCK 1** | **Full Paper (Part A + Part B)** | **3 hrs 00 mins** | 3 hrs 30 mins | 2h 45m timed solving + 15m quick review. Always do this while your brain is freshest. |
| **BLOCK 2** | **Sketching Basics & Assignments** | **1 hr 30 mins** | 2 hrs 30 mins | Line drills, perspective, figures, and assignment problems. Can be done in one sitting or split into two 45m sprints. |
| **BLOCK 3** | **Workout (10k Steps / 1km Run)** | **2 hrs 00 mins** | 2 hrs 00 mins | Physical reset and sleep-anchor. Zero guilt—this keeps your brain sharp for the other 3 blocks. |
| **BLOCK 4** | **Creative & Framework Work** | **2 hrs 00 mins** | 3 hrs + (Open) | Blender, design systems, frameworks, passion projects. Your reward block—scale up as much as you want once Exam Prep is done. |
| **TOTAL** | **Daily Output** | **8 hrs 30 mins** | **11 hrs 00 mins+** | Leaves 7.5–8 hrs for sleep and 4.5–7 hrs for meals, rest, and buffer. |

## Part 3: Biphasic Sleep & Eliminating the Afternoon Crash

### Why You Crash in the Afternoon & How Biphasic Sleep Solves It
Splitting sleep into **6 hours at night + a 1.5-hour afternoon nap** is an established method called **Biphasic (or Siesta) Sleep**.

#### 1. Four Biological Reasons for the Afternoon Crash
* **Circadian Misalignment:** When your body clock is anchored to 2:00 AM – 10:00 AM and you wake up at 6:00 AM, your brain is still pumping melatonin until 9:00 AM. By 2:00 PM, your body feels like it has been awake since the middle of the night.
* **The Post-Awakening 7–8 Hour Dip:** Humans are naturally biphasic. About 7 to 8 hours after waking up (around 1:00 PM – 3:00 PM for a 6:00 AM riser), core body temperature and alertness naturally dip.
* **Morning Adenosine & Electrolyte Depletion:** Walking 8–10 km in the morning depletes sodium, potassium, and glycogen. Combined with early caffeine, it causes an adenosine crash around 1:30 PM.
* **Heavy Carbohydrate Lunch:** Eating heavy carbs right before 2:00 PM spikes insulin and triggers drowsiness.

#### 2. The Biphasic Verdict (6h Night + 90m Nap vs. 5h Night)
* **6h Night (4 Cycles) + 90m Afternoon Nap (1 Cycle) = 7.5 Hours Total:** Ideal. Gives you two distinct "mornings" every day.
* **Why 90 Minutes Matters:** A full human sleep cycle is $90\text{ minutes}$ ($\text{Light Sleep} \rightarrow \text{Deep Sleep} \rightarrow \text{REM}$). If you sleep for $45\text{–}60\text{ minutes}$, you wake up in deep slow-wave sleep with severe **sleep inertia** (grogginess). Always nap for either **$25\text{ minutes}$** (power nap) or a full **$90\text{ minutes}$** ($1\text{ hr } 35\text{ mins}$ on the timer).
* **Anti-Crash Levers:**
  1. Drink lemon water + a pinch of salt after your 8–10 km morning walk.
  2. Delay your first coffee/tea by 60–90 minutes (have it after your walk and shower, right before Sketching).
  3. Keep lunch light before the 90-minute Siesta.

### The "Bad Day" Emergency Protocol (3h 15m Streak-Saver Floor)
* **Trigger:** Use ONLY when you slept terribly, woke up past 11:30 AM, feel sick, or lost half the day to an unavoidable emergency.
* **Golden Rule:** Never take a "Zero Day," and **never allow two Emergency Days in a row.**
  * [ ] **Emergency Domino 1 (Workout):** **45 Mins** — 1 km run + brisk 3–4 km walk for fresh air.
  * [ ] **Emergency Domino 2 (Sketching):** **30 Mins** — 2 pages of rapid perspective/figure warm-ups.
  * [ ] **Emergency Domino 3 (CEED Paper):** **1 Hr 00 Min** — 15 timed Part A questions + 1 Part B sketch.
  * [ ] **Emergency Domino 4 (Blender/Work):** **1 Hr 00 Min** — Focused framework or 3D practice.

    function getDateStrFromOffset(dayIndex) {
      const d = new Date(START_DATE);
      d.setDate(d.getDate() + dayIndex);
      return d.toISOString().split('T')[0];
    }

    function isDayComplete(dayRecord) {
      if (!dayRecord) return false;
      if (dayRecord.shieldUsed) return true;
      const coreIds = ['d1', 'd2', 'd3', 'd4'];
      return coreIds.every(id => dayRecord.completed && dayRecord.completed[id]);
    }

    function calculateStreak() {
      let streak = 0;
      const allDates = [];
      for (let i = 0; i < TOTAL_DAYS; i++) {
        allDates.push(getDateStrFromOffset(i));
      }
      const upToIndex = allDates.indexOf(currentDateStr);
      for (let i = upToIndex; i >= 0; i--) {
        const rec = state.days[allDates[i]];
        if (isDayComplete(rec)) {
          streak++;
        } else if (i === upToIndex) {
          continue;
        } else {
          break;
        }
      }
      return streak;
    }

    function toggleDomino(id) {
      const day = ensureDayRecord(currentDateStr);
      const dom = DOMINOS.find(d => d.id === id);
      if (day.completed[id]) {
        delete day.completed[id];
        state.xp = Math.max(0, state.xp - dom.xp);
      } else {
        day.completed[id] = true;
        state.xp += dom.xp;
      }
      saveState();
    }

    function toggleEmergencyMode() {
      const day = ensureDayRecord(currentDateStr);
      if (!day.emergency) {
        const prevDate = new Date(currentDateStr + 'T00:00:00');
        prevDate.setDate(prevDate.getDate() - 1);
        const prevStr = prevDate.toISOString().split('T')[0];
        if (state.days[prevStr] && state.days[prevStr].emergency) {
          alert('⚠️ Golden Rule Violation: Never allow two Emergency Days in a row! You used Emergency Mode yesterday—push for the standard floor today.');
          return;
        }
      }
      day.emergency = !day.emergency;
      saveState();
    }

    function useStreakShield() {
      const day = ensureDayRecord(currentDateStr);
      if (day.shieldUsed) {
        alert('🛡️ A Streak Shield is already active on this date.');
        return;
      }
      if (state.shields <= 0) {
        alert('No Streak Shields left! Complete 7 full days in a row to earn +1 Shield.');
        return;
      }
      if (confirm(`Use 1 🛡️ Streak Shield to protect your streak on ${currentDateStr}? (${state.shields} remaining)`)) {
        state.shields--;
        day.shieldUsed = true;
        saveState();
      }
    }

    function triggerWakeUp() {
      const day = ensureDayRecord(currentDateStr);
      day.wakeTimestamp = Date.now();
      saveState();
    }

    function updateWakeClock() {
      const day = ensureDayRecord(currentDateStr);
      const el = document.getElementById('wakeClock');
      if (!day.wakeTimestamp) {
        el.textContent = 'Wake + 00:00';
        return;
      }
      const diffMins = Math.floor((Date.now() - day.wakeTimestamp) / 60000);
      const hrs = String(Math.floor(diffMins / 60)).padStart(2, '0');
      const mins = String(diffMins % 60).padStart(2, '0');
      el.textContent = `Wake + ${hrs}:${mins}`;
    }

    function startDominoTimer(id) {
      const day = ensureDayRecord(currentDateStr);
      const dom = DOMINOS.find(d => d.id === id);
      const mins = day.emergency ? dom.emergencyMins : dom.normalMins;
      activeDominoId = id;
      timerSecondsLeft = mins * 60;
      timerPaused = false;
      document.getElementById('timerCard').classList.remove('hidden');
      document.getElementById('activeTimerTitle').textContent = `${dom.badge}: ${dom.title}`;
      document.getElementById('pauseResumeBtn').textContent = 'Pause';
      if (timerInterval) clearInterval(timerInterval);
      timerInterval = setInterval(() => {
        if (!timerPaused && timerSecondsLeft > 0) {
          timerSecondsLeft--;
          renderTimerDigits();
          if (timerSecondsLeft === 0) {
            clearInterval(timerInterval);
            alert(`🎉 Timer Complete for ${dom.title}!`);
            if (!day.completed[id]) toggleDomino(id);
          }
        }
      }, 1000);
      renderTimerDigits();
    }

    function renderTimerDigits() {
      const h = String(Math.floor(timerSecondsLeft / 3600)).padStart(2, '0');
      const m = String(Math.floor((timerSecondsLeft % 3600) / 60)).padStart(2, '0');
      const s = String(timerSecondsLeft % 60).padStart(2, '0');
      document.getElementById('timerDisplay').textContent = `${h}:${m}:${s}`;
    }

    function pauseResumeTimer() {
      timerPaused = !timerPaused;
      document.getElementById('pauseResumeBtn').textContent = timerPaused ? 'Resume' : 'Pause';
    }

    function completeActiveTimerDomino() {
      if (activeDominoId) {
        const day = ensureDayRecord(currentDateStr);
        if (!day.completed[activeDominoId]) toggleDomino(activeDominoId);
      }
      closeTimer();
    }

    function closeTimer() {
      if (timerInterval) clearInterval(timerInterval);
      document.getElementById('timerCard').classList.add('hidden');
    }

    function changeDate(val) {
      currentDateStr = val;
      renderAll();
    }

    function formatMins(m) {
      const h = Math.floor(m / 60);
      const rem = m % 60;
      if (h === 0) return `${m}m`;
      if (rem === 0) return `${h}h 00m`;
      return `${h}h ${rem}m`;
    }

    function renderAll() {
      document.getElementById('datePicker').value = currentDateStr;
      const day = ensureDayRecord(currentDateStr);

      const dayIndex = Math.max(0, Math.min(86, Math.round((new Date(currentDateStr + 'T00:00:00') - START_DATE) / 86400000)));
      document.getElementById('dayBadge').textContent = `DAY ${dayIndex + 1} / 87`;
      const phaseEl = document.getElementById('phaseLabel');
      if (dayIndex < 30) phaseEl.textContent = 'Phase 1: Endurance & Accuracy';
      else if (dayIndex < 65) phaseEl.textContent = 'Phase 2: Speed & Storytelling';
      else phaseEl.textContent = 'Phase 3: Exam-Clock Lock-In';

      const streak = calculateStreak();
      document.getElementById('streakCount').textContent = streak;
      document.getElementById('shieldCount').textContent = state.shields;
      const lvl = Math.floor(state.xp / 500) + 1;
      document.getElementById('xpDisplay').textContent = `⚡ ${state.xp} XP (Lvl ${lvl})`;

      const emBtn = document.getElementById('emergencyBtn');
      const emText = document.getElementById('emergencyBtnText');
      if (day.emergency) {
        emBtn.classList.add('emergency-active');
        emText.textContent = 'Bad Day Floor: ON (3h 15m)';
      } else {
        emBtn.classList.remove('emergency-active');
        emText.textContent = 'Bad Day Mode: OFF';
      }

      const list = document.getElementById('dominoList');
      list.innerHTML = '';
      DOMINOS.forEach(dom => {
        const done = !!day.completed[dom.id];
        const mins = day.emergency ? dom.emergencyMins : dom.normalMins;
        const card = document.createElement('div');
        card.className = `glass rounded-2xl p-4 transition ${done ? 'domino-done' : ''}`;
        card.innerHTML = `
          <div class="flex items-start justify-between gap-3">
            <div class="flex-1">
              <div class="flex items-center gap-2">
                <span class="text-[10px] font-extrabold px-2 py-0.5 rounded bg-zinc-800 text-zinc-200 border border-zinc-700">${dom.badge}</span>
                <span class="text-xs font-mono text-zinc-400">${dom.offset}</span>
                <span class="text-xs font-bold text-amber-400">⏱ ${formatMins(mins)}</span>
              </div>
              <h3 class="text-base font-bold mt-1 ${done ? 'line-through text-emerald-300' : 'text-white'}">${dom.title}</h3>
              <p class="text-xs text-zinc-400 mt-1 leading-relaxed">${dom.desc}</p>
            </div>
            <button onclick="toggleDomino('${dom.id}')"
              class="w-11 h-11 rounded-2xl flex items-center justify-center font-black text-lg border transition shrink-0 ${
                done ? 'bg-emerald-500 border-emerald-400 text-black' : 'bg-zinc-900 border-zinc-700 text-zinc-400 hover:border-zinc-500'
              }">
              ✓
            </button>
          </div>
          <div class="mt-3 pt-2.5 border-t border-zinc-800/80 flex items-center justify-between">
            <span class="text-[11px] text-emerald-400 font-semibold">+${dom.xp} XP</span>
            <button onclick="startDominoTimer('${dom.id}')" class="text-xs font-bold px-3 py-1 rounded-lg bg-zinc-800 hover:bg-zinc-700 text-indigo-300 border border-zinc-700">
              ▶ Start ${formatMins(mins)} Timer
            </button>
          </div>
        `;
        list.appendChild(card);
      });

      const grid = document.getElementById('heatmapGrid');
      grid.innerHTML = '';
      for (let i = 0; i < TOTAL_DAYS; i++) {
        const dStr = getDateStrFromOffset(i);
        const rec = state.days[dStr];
        const complete = isDayComplete(rec);
        let bg = 'bg-zinc-800/90 text-zinc-400';
        if (rec && rec.shieldUsed) bg = 'bg-sky-500 text-black font-black';
        else if (complete && rec.emergency) bg = 'bg-amber-500 text-black font-black';
        else if (complete) bg = 'bg-emerald-500 text-black font-black';

        const isSelected = dStr === currentDateStr ? 'ring-2 ring-white' : '';
        const cell = document.createElement('button');
        cell.className = `h-7 rounded-md text-[10px] flex items-center justify-center transition ${bg} ${isSelected}`;
        cell.textContent = i + 1;
        cell.onclick = () => changeDate(dStr);
        grid.appendChild(cell);
      }

      updateWakeClock();
    }

    function exportData() {
      const blob = new Blob([JSON.stringify(state, null, 2)], { type: 'application/json' });
      const a = document.createElement('a');
      a.href = URL.createObjectURL(blob);
      a.download = `ceed-domino-streak-backup-${currentDateStr}.json`;
      a.click();
    }

    function importData(e) {
      const file = e.target.files[0];
      if (!file) return;
      const reader = new FileReader();
      reader.onload = (evt) => {
        try {
          state = JSON.parse(evt.target.result);
          saveState();
          alert('✅ Streak backup restored!');
        } catch (err) {
          alert('Invalid backup file.');
        }
      };
      reader.readAsText(file);
    }

    setInterval(updateWakeClock, 15000);
    renderAll();
  </script>
