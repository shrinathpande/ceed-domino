Build and maintain a mobile-first, installable Progressive Web App (PWA) called "CEED 87-Day Domino Tracker" (spanning Oct 22, 2026 to Jan 17, 2027).

### Context from our previous design session:
1. **Zero-Clock Domino System:** The user does not use wall-clock times. The day starts at `Wake + 0:00` ("Start Day" button) and tracks relative offset time.
2. **The 4 Core Dominos + Biphasic Sleep:**
   - **Launchpad:** 15m (Wake + 0:00) — Water + pinch of salt, shoes on, zero scrolling.
   - **Domino 1 (Workout):** 2h 00m floor (Wake + 0:15) — Peaceful morning walk (8–10 km) / 1 km run.
   - **Domino 2 (Sketching):** 1h 30m floor / 2h 30m ceiling (Wake + 3:00) — Basic sketching, perspective grids, human figures, assignments.
   - **Domino 3 (CEED Paper):** 3h 00m floor / 3h 30m ceiling (Wake + 4:30) — 2h 45m Full Paper (35 Part A + 5 Part B on A4 templates) + 15m Error Log.
   - **Siesta Reset:** 1h 35m (Wake + 8:00) — 1 full 90-min sleep cycle (+5m fall asleep) or 25m power nap.
   - **Domino 4 (Creative & Framework Work):** 2h 00m floor / Open ceiling 3–4h+ (Wake + 10:00) — Blender, design systems, framework projects.
   - **Core Night Sleep:** 6h 00m (Wake + 18:00) — 4 full 90-min cycles.
3. **Bad Day Emergency Protocol (Streak Saver Mode):**
   - Toggling "Emergency Mode" switches the daily floor to a 3h 15m minimum so a bad sleep day doesn't break the streak:
     - Domino 1: 45m (1 km run + brisk walk)
     - Domino 2: 30m (2 pages rapid figure/perspective drills)
     - Domino 3: 1h 00m (15 Part A Qs + 1 Part B sketch)
     - Domino 4: 1h 00m (Focused Blender/framework sprint)
   - **Hard Rule:** Block the user from activating Emergency Mode two days in a row!
4. **Gamified Streak & Streak Freeze Mechanics:**
   - Track Current Streak (🔥), XP points (+100 XP per Domino, +150 XP bonus for clearing all 4 Dominos), and a visual 87-Day Heatmap Grid (Oct 22, 2026 – Jan 17, 2027).
   - **Streak Freeze / Shield (🛡️):** User starts with 2 Streak Shields and earns +1 Shield for every 7-day full streak (max 3 held). If a day is missed, allow consuming a Streak Shield to protect the streak.
   - Include a built-in countdown timer modal for each Domino with audio/vibration alerts, LocalStorage persistence, and JSON backup export/import.
